If tiles aren't found, move the brightness slider until the mask covers the tile faces. If different tiles get paired, raise strictness; if identical tiles don't pair, lower it.
How it works: it finds the bright, low-color tile faces, keeps only faces that are fully visible (a tile with another tile on top shows only part of its face), compares each tile's picture against the others, and groups identical ones. A tile counts as "free" when no visible tile touches its left or its right side. That's a best guess from one camera angle, so double-check before tapping. Flower and season tiles match within their set in most games, but they look different, so this tool won't pair them.
